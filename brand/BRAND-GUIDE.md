# VortexBox Brand Guide v1

## Logo Variants

Version active: V seul (inspire du logo envoye).
- Hero logo: `brand/vortexbox-logo-hero.png`
- Header logo: `brand/vortexbox-logo-header.svg`
- App/icon mark: `brand/vortexbox-icon.svg`
- Monochrome light: `brand/vortexbox-logo-mono-light.png`
- Monochrome dark: `brand/vortexbox-logo-mono-dark.png`

## Recommended Usage
- Hero sections on dark backgrounds: use `vortexbox-logo-hero.png`
- Navigation/header: use `vortexbox-logo-header.svg`
- Favicons and compact badges: use `vortexbox-icon.svg` or generated PNG favicons
- Light print/backgrounds: use monochrome dark
- Dark print/backgrounds: use monochrome light

## Safe Area
- Keep a clear margin around the logo equal to at least 0.5x the icon height.
- Do not place text or UI controls inside this area.

## Minimum Size
- Header logo: minimum height 32px
- Icon-only logo: minimum 24px
- Favicon: 16px and 32px variants included

## Colors
- Core cyan: `#24D7FF`
- Core blue: `#2B66FF`
- Accent aqua: `#8AF2FF`
- Deep navy: `#07182F`
- Dark base: `#040A17`

## Motion
- Navigation shimmer and float should stay subtle.
- Disable motion when `prefers-reduced-motion: reduce` is set.

## Exports Included
- `brand/vortexbox-og-1200x630.png`
- `favicon-vb.svg`
- `favicon-vb.png`
- `favicon-32x32.png`
- `favicon-16x16.png`
- `apple-touch-icon.png`

## Do Not
- Stretch logos non-proportionally
- Add heavy shadows/glows beyond brand presets
- Use low-contrast overlays that reduce readability
